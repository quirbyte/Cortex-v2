# Cortex

Cortex is a modern, high-performance, multi-tenant SaaS platform built on the cutting edge of the Next.js ecosystem. Leveraging Turbopack, Prisma, and modern styling architectures, Cortex delivers a seamless experience with lightning-fast execution layers and real-time state consistency.

## 🚀 Tech Stack

- **Framework:** Next.js (App Router, Turbopack optimized)
- **Database ORM:** Prisma
- **Authentication:** NextAuth.js
- **Styling:** Tailwind CSS
- **Components & Animations:** Lucide React & Framer Motion
